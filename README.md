# Campus-Connect-Event-Portal
Campus Connect is a student-friendly web platform designed to make campus event management easier and more organised. It provides students with a centralised place to explore upcoming college events, view event details, and register for activities.
The website aims to improve communication between students and event organisers by making event information easily accessible. It offers a simple and user-friendly interface that helps students stay updated about campus activities, participate in events, and engage more actively in college life.
Key Features:
View upcoming college events.
Explore event details and schedules.
Register for different campus activities.
Easy-to-use and student-friendly interface.
Centralised platform for campus event information.
Main Objective: To create a digital platform that connects students with campus events and encourages greater student participation.
